## Завдання 1 — мінімум у BST

Найменше значення в BST завжди знаходиться **в найлівішому вузлі**.
Ця властивість випливає з інваріанту BST: для кожного вузла все що
зліва менше за нього. Тому достатньо йти по `node.left` поки воно
не стане `None`.

```python
def find_min(tree):
    node = tree.root
    while node.left is not None:
        node = node.left
    return node.value
```

Складність: O(h), де h — висота дерева. Для збалансованого
дерева — O(log n), для виродженого (вставка вже відсортованих
значень) — O(n).

## Завдання 2 — сума всіх значень

BST-властивість тут не допомагає: щоб порахувати суму, доводиться
відвідати кожен вузол. Рекурсивний обхід дає O(n):

```python
def _sum(node):
    if node is None:
        return 0
    return node.value + _sum(node.left) + _sum(node.right)
```

## Завдання 3 — оптимальне з'єднання кабелів

Маємо `n` кабелів різних довжин. Треба об'єднати їх по два за раз
у один кабель. Вартість одного з'єднання = сума довжин двох кабелів,
загальна вартість = сума всіх з'єднань. Знайти порядок з мінімальною
загальною вартістю.

### Жадібний алгоритм через min-heap

На кожному кроці беремо **два найкоротші** кабелі, з'єднуємо, кладемо
результат назад у купу. Повторюємо поки не залишиться один кабель.

```python
heap = list(cables)
heapq.heapify(heap)
total = 0
while len(heap) > 1:
    a = heapq.heappop(heap)
    b = heapq.heappop(heap)
    merged = a + b
    total += merged
    heapq.heappush(heap, merged)
```

Складність: O(n log n) — кожна з n операцій push/pop коштує O(log n).

### Чому жадібний оптимальний

Кожен оригінальний кабель потрапляє в загальну вартість стільки разів,
скільки рівнів він пройшов у "дереві злиття" (бо на кожному рівні він
входить у нову суму). Щоб мінімізувати загальну вартість, **короткі
кабелі мають бути глибше** — тобто зливатися першими.

Це та сама ідея, що в основі алгоритму Хаффмана для оптимального
префіксного кодування.

### Приклад прогону

Кабелі: `[8, 4, 6, 12, 3, 1, 5]`

```
step  1: merge 1 + 3 = 4   (total cost: 4)
step  2: merge 4 + 4 = 8   (total cost: 12)
step  3: merge 5 + 6 = 11  (total cost: 23)
step  4: merge 8 + 8 = 16  (total cost: 39)
step  5: merge 11 + 12 = 23  (total cost: 62)
step  6: merge 16 + 23 = 39  (total cost: 101)

оптимальна вартість: 101
наївне об'єднання (у порядку списку): 166
економія від жадібного: 65 (39.2%)
```

Дерево злиття (`merge_tree.png`): зелені листки — оригінальні кабелі,
червоні внутрішні вузли — результати з'єднань. Корінь (39) — довжина
фінального кабелю, а сума всіх внутрішніх вузлів = 101 — це й
є загальна вартість.

Наївне порівняння — це fold-left, тобто з'єднання у тому порядку,
в якому кабелі прийшли в списку. На цьому прикладі воно коштує 166,
тобто на 64% дорожче за оптимум.
